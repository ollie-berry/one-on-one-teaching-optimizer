# 项目定义、角色与规则优先级
## 1. 项目定位

本项目的目标不是只让某个一对一教学 demo 能跑通，也不是只沉淀某一版 prompt 文本。

本项目要建立的是一个可持续继承判断的一对一教学 prompt 优化系统，使后续 PM、优化 Agent 或其他参与者继续参与迭代时，不需要重新追问：

- 为什么当前阶段要这样设计；
- 什么样的 teacher 输出算好；
- 什么样的问题必须修；
- 什么样的问题只是可接受残留；
- 哪些判断只适用于当前场景；
- 哪些 prompt 修法曾经有效；
- 哪些修法会造成过修复；
- 哪些历史风险需要继续在场景规则或案例资产中保留。

本项目沉淀的不只是 prompt 和评测结果，还包括：

- 场景职责定义；
- 问题定义；
- 评测标准；
- badcase 归因；
- 可接受残留判断；
- prompt 修改方法；
- PM 已确认的业务判断；
- 每轮试错后的有效结论。

## 2. 核心目标

本项目优化的是一对一教学场景下的 `teacher_prompt`。

目标是让 teacher prompt 在多轮对话中稳定做到：

1. 知道当前教学阶段该做什么；
2. 知道讲到哪里应该停；
3. 能围绕学生理解路径推进；
4. 能提出真正服务教学的问题；
5. 能接住学生输入并据此调整下一步；
6. 能避免知识错误、编造、跑题、扩题、内部术语外露和机械表达；
7. 能在不同学科、不同模块中迁移一对一教学的通用能力，同时尊重具体场景规则中的差异。

## 3. 系统需要持续回答的关键问题

本系统不是历史会话的简单整理，也不是某一版 Prompt 的拼接，更不是把所有坏例子改写成禁止项。

它要沉淀的是本项目逐步形成的一套**一对一教学决策系统**：当面对一个新的学科、年级或教学模块时，设计者能够判断：

1. 当前教学阶段究竟要完成什么；
2. 老师应该讲什么、讲到什么程度、何时停止；
3. 什么时候需要提问，应该问什么，问题承担什么教学功能；
4. 学生回答后，老师如何真正基于学生输入改变下一步；
5. 不同学科、学段和模块之间，哪些原则可以迁移，哪些不能机械迁移；
6. 测试输出出现问题时，如何区分 Prompt、场景定义、入参、测试流程和学生模拟器问题；
7. 哪些问题必须修，哪些只是可接受残留，哪些修改会导致过修复；
8. 如何把 PM 已确认的显性与隐性裁决持续沉淀，而不是每次重新讨论。

## 4. 角色边界

### 4.1 teacher_prompt

`teacher_prompt` 是被优化对象。它决定 AI 老师如何面对学生进行多轮教学输出。

评估时只评价 teacher 输出质量，不评价 student simulator 的教学能力。

### 4.2 student_prompt

`student_prompt` 是学生模拟器，用于在测试中提供学生回答、错误回答、不知道、模糊回答或其他互动输入。

如果 student simulator 明显异常，优化 Agent 不能直接把问题归因到 teacher prompt。

### 4.3 优化 Agent

优化 Agent 是评测、分析、归因、候选 prompt 生成和知识沉淀助手。

优化 Agent 需要做到：

- 阅读项目上下文和对应场景知识；
- 基于测试输出识别问题；
- 区分 prompt 问题、场景定义问题、入参问题、测试流程问题和 student simulator 问题；
- 在 PM 确认后生成候选 prompt；
- 在项目收口时提出场景规则、badcase、可接受残留或 Prompt 修改方法的更新建议。

优化 Agent 不能替代 PM 做最终业务确权。

### 4.4 PM

PM 是业务判断、优化方向、知识确权和版本及知识更新的最终负责人。

所有关键判断，包括“是否要修”“是否可接受”“是否进入长期知识库”，必须由 PM 确认。

## 5. 全局判断优先级

当多个目标冲突时，优化 Agent 必须按以下优先级判断。

1. 知识准确与内容安全边界；
2. 阶段职责匹配与停点控制；
3. 教学推进有效性；
4. 学生输入承接；
5. 互动与提问质量；
6. 表达自然度与一对一人感；
7. 风格丰富性。

低优先级目标不能破坏高优先级目标。

例如：

- 不能为了更有趣而牺牲知识准确；
- 不能为了更多互动而制造无意义问题；
- 不能为了避免跑题而让讲解缺少必要解释；
- 不能为了控制长度而破坏教学推进；
- 不能为了消除轻微问题而引入更大的系统性回归。

## 6. 规则冲突时的来源顺序

规则发生冲突时，当前用户或 Owner 的明确裁决优先于旧规则；本文件中的项目目标、底线和全局优先级不能被其他文件推翻；在不违反全局底线时，场景与产品规则中适用于当前学科、学段、模块和阶段的具体规则优先于通用判断。模型只负责整合这些认知，不自行改写权威顺序。
