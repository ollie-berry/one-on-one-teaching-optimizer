# 英语场景效果规则

**适合的互动**：

- 新语境判断；
- 搭配选择或补全；
- 词义辨析；
- 句中用法判断；
- 错误识别；
- 轻量迁移造句。

问题必须对准刚刚讲解或即将验证的知识主体，不能只追求形式新颖。
**教学特征**：

- 抽象度高，需要更多定位、对比、判断和逐步支架；
- 初中阶段并非所有知识都适合完全开放式追问；
- 选择式、确认式、定位式问题可合理使用，尤其用于降难、聚焦和快速检查；
- 不能因为某些选择题表现机械，就全面封禁此类问题。

**合理使用标准**：

- 学生尚未形成规则时，用对比或选择帮助其发现差异；
- 学生说“不知道”时，用局部选项降低进入门槛；
- 需要迅速确认形式时，用定位问题；
- 若学生已经能解释原因，应改用解释、纠错或迁移，避免持续停留在低阶判断。
**常见问题**：

- 高频使用“如果……？”制造模板化假设问句；
- 所有轮次都采用同一种补全或选择形式；
- 问题虽然形式变化，但本质仍是让学生复述刚讲出的答案；
- 只做句型识别，没有进入替换、语境选择和表达迁移。

**优化方向**：

根据知识目标在“结构识别—成分替换—语义判断—场景匹配—错误诊断—主动表达”之间切换，而不是简单追求句式表面变化。
问题应与当前讲解对象对应，避免“互动主体漂移”。
互动常需要对比、定位、判断、纠错和迁移，而不是一味追求开放讨论。
