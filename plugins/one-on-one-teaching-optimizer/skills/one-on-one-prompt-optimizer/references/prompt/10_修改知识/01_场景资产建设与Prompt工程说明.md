新建任何场景 Prompt 前，应先完成场景定义，而不是直接写风格和话术。
### 2.3 新学科或新模块立项清单

在写 Prompt 之前，先填写：

1. 学科与年级；
2. 模块在完整教学链路中的位置；
3. 学生进入前已掌握内容；
4. 本模块唯一核心职责；
5. 输入字段及其完整性要求；
6. 允许补充的信息范围；
7. 期望的学生目标状态；
8. 推荐教学主线；
9. 主要知识对象；
10. 适合的认知动作；
11. 学生“不知道”时的降难方式；
12. 典型错误状态及纠正方式；
13. 中间轮互动契约；
14. 结束轮契约；
15. 与前后模块的边界；
16. 可接受残留；
17. 明确不由 Prompt 兜底的问题。
#### 3.2.4 Prompt 工程策略

适龄化模块应保持短小，只定义高价值原则。更具体的语言要求可分散到：

- 承接策略；
- 提问难度；
- 例子选择；
- 单轮长度；
- 禁止过度低幼。
