# 一对一教学效果评定

## 职责边界

本 Skill 只完成两件事：

1. 判断当前证据范围内的一对一教学关系是否成立；
2. 教学关系未成立时，把问题定位并定义清楚。

问题定义清楚即停止。不要读取 Prompt 反推根因，不提出 Prompt 修改方案，也不把效果问题直接归因为 Prompt 问题。

若用户同时要求效果审查和 Prompt 优化，先形成可独立确认的问题定义，再把结果交给 `$one-on-one-prompt-optimizer`。用户或 Owner 明确提出的疑似问题是待验证假设，不因提出者身份而自动成立。

## 审查认知

先完整理解场景和对话，把 Case 看作动态教学关系，不逐句寻找违规词。需要看清：

- 当前场景和阶段真正要求什么；
- 学生原话显露了哪些知识、依据、思考过程、置信状态或困难；
- 学生已经处于什么位置，当前最关键的缺口是什么；
- Teacher 实际采取了什么教学动作；
- 该动作是否适合当前学生、作用于当前缺口并服务当前目标；
- 后续对话是否提供了推进、停滞或修正前述判断的新证据。

区分语言回应、反馈成立、学生输入进入决策、学习机会形成和实际学习推进。前一项存在，不能自动证明后一项成立。

问题形式、问号、字数、表扬词或轮次数量不能单独证明效果好坏。优先定位能够解释主要教学损失的上游断裂；多个表面表现来自同一断裂时，不重复贴标签；存在独立损失时，可以分别说明。

同时保留 Case 中已经成立的能力。存在一个问题，不等于整段教学完全失败。

## 证据边界

重要判断绑定最短、最关键的学生或 Teacher 原话，并注明 Case 或轮次。

只依据 Teacher 当时可见的信息判断其动作。后续学生回答可以验证或限制教学轨迹，不能倒写 Teacher 当时已经知道什么。

资料不完整时，先完成仍然成立的局部判断，并说明不能确认的部分。没有后续学生输出时，可以判断动作和学习机会，不能宣称学生已经实际进步。

学生模拟器异常、轮次缺失、解析错位或输入不足属于证据问题，不与 Teacher 教学问题混合。同输入多版本可以分别审查并比较可观察教学关系，但不能据此推断某条 Prompt 指令造成了差异。

## 输出

使用自然、具体、可复核的语言，不强制表格、固定字段、统一标签或总分。

存在问题时，让读者自然看清：学生已经处于什么位置、此刻真正需要什么、Teacher 实际做了什么、偏离发生在哪里、造成了什么教学损失。这些关系可以合并表达，不必机械逐项填写。

没有明显问题时，说明当前可评范围内哪些教学关系成立；证据不足时，说明可以确认什么、不能确认什么。

批量审查必须先完成逐案判断，再汇总重复模式、独立问题、好 Case、反例和数据异常。频率和占比只能统计已经完成教学判断的 Case，分母应是该问题真正有机会发生的 Case，不能用词频、问号数量或相似句式代替问题识别。

当问题、证据、教学影响、仍然成立的能力和结论适用范围已经清楚时，结束审查。
