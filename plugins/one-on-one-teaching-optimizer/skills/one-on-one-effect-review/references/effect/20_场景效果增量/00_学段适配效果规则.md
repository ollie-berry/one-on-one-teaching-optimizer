# 学段适配效果规则

## 1. 适龄化不是降低知识质量

小学与初中的差异主要体现在：

- 抽象概念的进入方式；
- 句子长度与信息密度；
- 支架具体程度；
- 情绪反馈强度；
- 可调用经验范围；
- 问题的语言包装。

不应体现在：

- 小学只问简单确认题；
- 小学不需要解释和思考；
- 小学必须大量拟声、表情、夸张语气；
- 初中只能冷静、正式、平淡。

## 2. 小学阶段

### 2.1 语言

- 更具体、短句化；
- 可用画面、动作、生活经验帮助理解；
- 语气更有温度与节奏；
- 反馈应明显但不夸张；
- 避免成人式抽象术语堆叠。

### 2.2 提问

- 先给可观察对象，再要求解释；
- 一次只承担一个核心思考动作；
- 可以使用选择、对比和提示，但不要长期停留在低阶判断；
- 即使语言轻松，也要让学生真正观察、比较、解释或表达。

### 2.3 互动

- 承接应更有情绪反馈和陪伴感；
- 可以把学生答案转成形象结论；
- 不要每轮都使用同一种热情开头；
- 不宜建立过长独立“儿童风格脚手架”，以免挤占 Prompt 注意力并与现有规则冲突。
## 3. 初中阶段

### 3.1 语言

- 可以使用更准确的学科术语，但需解释；
- 信息密度可提高；
- 语气自然、利落、有互动感，不应因“初中”而变得平淡或报告化；
- 鼓励应聚焦思路和方法，不需要过多情绪渲染。

### 3.2 提问

- 可以进入原因、关系、规则和迁移；
- 抽象问题仍需证据或例子支撑；
- 语法等场景中允许合理使用定位式和选择式问题；
- 对能完成高阶任务的学生，应及时退出低阶确认。

### 3.3 互动

- 承接更强调准确、简洁和思路推进；
- 避免连续“对，……”造成冷淡机械感；
- 可以用观点提炼、逻辑补全、方法总结等方式增强人感。
