# 评测执行与交接规则

## 1. 评测执行原则

1. 不先计算分数。评测的首要任务是识别具体问题、定位证据、判断影响并区分问题来源。
2. 不使用“效果不好”“不自然”“互动不足”“需要优化”等模糊结论代替分析。
3. 每个核心判断都应落到具体轮次、输出片段和被破坏的教学动作。
4. 先判断知识、边界和阶段职责，再判断话术、风格和表达自然度。
5. 先判断问题是否来自 Teacher Prompt，再决定是否通过 Prompt 修改处理。
6. 不为少量局部现象牺牲跨 case 稳定性。
## 2. 确认当前阶段应该完成什么

从当前场景规则和本轮目标中判断：

- 当前阶段的核心职责是什么；
- 学生经过这一阶段应获得什么；
- teacher 允许做什么；
- teacher 禁止做什么；
- 输出到什么程度应停止。

如果没有对应场景规则，优化 Agent 只能按全局原则做初步判断，并标记“需要 PM 确认”。

## 3. 定位被破坏的教学动作

不要只看表面话术，要判断它破坏了哪个教学动作。

常见教学动作包括：

- 阶段任务完成；
- 概念或内容讲解；
- 学生理解推进；
- 提问互动；
- 学生输入反馈；
- 内容边界控制；
- 学生侧表达。
## 4. 决定后续动作

根据问题来源和影响决定：

- 修改 Teacher Prompt；
- 补充或修正场景定义；
- 修正输入数据、学生模拟或测试流程；
- 暂不处理，继续观察更多 case；
- 回退本轮修改，重新定位根因。

## 5. 评测顺序

评测任何版本时，按以下顺序：

1. 知识准确与内容边界；
2. 阶段职责与停点；
3. 教学推进路径；
4. 学生输入承接；
5. 互动与提问质量；
6. 表达自然度；
7. 跨 case 稳定性。

不能先看语气是否好听，再判断教学是否成立。
## 6. 分析时

- 先进入具体场景，再判断输出；
- 先找教学失败点，再评价文风；
- 先区分问题来源，再决定改不改 Prompt；
- 所有重要结论绑定具体 case；
- 对不确定判断标记需 PM 确认；
- 不将本学科规则直接泛化到其他学科。
