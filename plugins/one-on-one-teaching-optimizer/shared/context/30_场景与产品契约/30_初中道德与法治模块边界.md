# 初中道德与法治模块与知识对象规则

初中道德与法治的知识点讲解和例题讲解共享学科知识边界，但承担不同教学职责。以下规则只适用于初中道德与法治；知识点讲解中的组织方式不能自动迁移为例题流程，例题中的解题方式也不能替代知识点理解。

## 1. 学科共通边界

### 1.1 核心知识对象

初中道德与法治常见的知识对象包括：

- 概念及其适用边界；
- 主体、对象、范围、条件与程度；
- 权利、义务、责任与行为规范；
- 国家机关的性质、职权及相互关系；
- 制度、国情、国策、价值要求及其作用；
- 材料事实、教材观点与二者之间的对应关系。
### 1.2 输入内容分层

使用结构化输入时，应区分：

- 学生需要理解或用于作答的教材知识、题目事实和材料证据；
- 帮助 Teacher 判断重点、易错点、解释方式或教学顺序的参考信息；
- 板块标签、教研术语、话术建议、固定答题框架等内部组织信息。

后两类内容不能仅因出现在输入中就直接转化为学生必须学习或复述的知识。易错点等参考信息若确实影响当前理解，应讲清其知识实质，而不是输出内部标签。

### 1.3 知识准确与扩展边界

生活情境可以帮助学生进入抽象概念，但不能仅凭一个生活例子生成新的法律定性、权利分类、机关程序、法定职权或制度关系。输入已经提供权威案例及其结论时，可在该依据范围内使用。

法律、制度、机关职权和权利义务属于高风险知识对象。对输入外内容的补充必须保持克制，不能把可能相关说成法定对应，也不能以现实评论替代教材知识。具体允许补充到什么范围，由当前场景的权威知识来源和业务要求另行确定。

### 1.4 行动要求的边界

“青少年怎么做”不是所有道德与法治知识的统一落点。国家机关、制度、国情、概念等知识不能为了形成正向收束而一律转成行动口号。是否进入行动理解，应由当前知识对象、输入依据和场景目标共同决定；具体触发范围仍需业务确权。

## 2. 道德与法治知识点讲解

**核心职责**：依据当前结构化知识输入，帮助学生准确理解本知识点的概念、对象、关系、意义、边界或明确行为要求，并在当前知识完成后收束。它不承担例题训练、完整专题复习、现实政治评论或下一模块教学。
## 3. 道德与法治例题讲解

**核心职责**：围绕当前题目的设问、题干或材料、选项及知识依据，帮助学生形成可解释的判断或答案，并完成整道题的必要收束。它不承担脱离当前题目的系统知识点讲解、扩展新题或无关现实议题讨论。
当前模块必须把答案建构到什么完整程度，取决于题型、学生状态、输入中的参考答案以及产品是否另有答案展示环节；学科层不统一规定必须逐点展示完整标准答案。
### 3.1 材料来源与回答判断

材料题中应区分：

- 材料明确写出的信息；
- 可由材料直接推出的信息；
- 教材知识补充；
- 无依据或与题目冲突的信息。

教材知识即使正确，也不能被说成“材料中写了”。学生引用的信息和 Teacher 用于解释或作答的信息都受同一来源边界约束。
是否必须设置固定末问、结束前至少需要多少学生理解证据，属于具体产品契约和场景目标，不能由本学科规则统一设定。
## 4. 知识点讲解与例题讲解的边界

| 维度 | 知识点讲解 | 例题讲解 |
|---|---|---|
| 核心对象 | 概念、边界、关系、意义或明确行为要求 | 设问、题干或材料、选项、知识依据与答案 |
| 主要目标 | 建立对当前知识对象的准确理解 | 完成当前题目的判断、论证或答案建构 |
| 内容组织 | 由知识对象及其关系决定 | 由设问限制、材料证据和答案缺口决定 |
| 互动职责 | 发现概念边界、关系和当前理解缺口 | 识别解题依据、辨析干扰、连接材料与知识 |
| 停点依据 | 当前必学知识与关键误解的处理状态 | 整题剩余任务与学生当前作答状态 |

知识点讲解中的“关系单元”不能成为例题的统一颗粒度；例题中的逐项排除、材料取证或规范答题结构，也不能成为知识点讲解的固定流程。两类模块可以共享识别学生状态、寻找当前缺口、选择教学动作和控制停点等通用决策原则，不能共享表面脚本。

## 5. 仍需场景或产品确权的边界

以下问题不能在当前学科规则中预先写死：

- 知识点讲解最终要求学生达到识别、解释、规范表达还是迁移应用中的哪一层；
- 哪些知识对象需要进入面向青少年的正向行动，以及行动理解的具体触发条件；
- Teacher 可以补充输入外教材、法律或制度知识的权威来源和范围；
- 主观题应展示到关键逻辑成立，还是需要呈现完整参考答案的全部得分点；
- 中间轮或结束前是否存在固定末问要求；
- 简单知识或整题结束前需要多少、何种学生理解证据才足够。

上述边界应由具体业务、内容来源和产品契约确定。缺少确权时，只能依据当前输入和通用教学原则作有边界判断，不能将一种测试做法升级为全学科规则。
