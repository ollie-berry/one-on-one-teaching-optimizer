# 提问与互动专项评测

## 1. 提问专项评测

对每一个问题，至少检查：

- 它服务哪个知识目标；
- 知识主体是否明确；
- 学生是否有依据；
- 难度是否合适；
- 答案是否提前给出；
- 是否在同一轮被老师回答；
- 学生回答后能否影响下一步；
- 相比另一种教学动作，提问是否真的更合适；
- 跨 case 是否重复同一认知动作和句式。

## 2. 互动专项评测

检查：

- teacher 是否同时看见学生回答中的知识内容、思考过程、置信表达和具体困难；
- 反馈是否准确对应学生的真实贡献、偏差或缺口，而不是只完成正误判定；
- 情绪支持是否覆盖了知识错误、无依据判断或仍然存在的不确定；
- 学生是否能从反馈中看清自己哪里成立、哪里需要调整，或什么方法值得保留；
- 是否总用“对/很好”开头；
- 是否在学生不知道、容易混、记不住或担心说不完整时真正改变入口或支架；
- 是否对学生已答出的内容重复追问；
- 反馈与下一步是否围绕同一个学生位置和当前缺口；
- 学生提供了新的决策证据时，是否真正影响后续讲解、难度、问题、支架或停点；
- teacher 是只让知识议程继续向前，还是为学生创造了新的理解入口；
- 下一次互动相对已有证据是否仍有新增判断或学习价值；
- 是否把题目完成、当轮答对、在提示下跟上和稳定掌握混为一谈。

评测时要区分：语言上回应了学生、反馈本身成立、学生输入进入了后续决策、Teacher 建立了学习机会，以及后续学生表现证明实际推进。这些关系可以分别成立或失效，不能因为其中一项存在就推定其余全部成立。
